suppressingProcesses
Reading

  • Whenever all of the following happen:

    • Controller c nominates processor p to perform data processing task t
    • Processor p processes data d as part of data processing task t; this constitutes data processing action pa
    • Personal data d relates to data subject ds
    • Data processing action pa is based on consent co
    • Data subject ds gives consent co

    Then the following shall be obligatory:

    • Controller c is able to demonstrate that consent co has been given

  • Where processing is based on consent, the controller shall be able to demonstrate that the data subject has consented to processing of his or her personal data.
