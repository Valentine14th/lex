# Lex

## Installation
### Build from source
From the root directory of this repository, run:
```bash
dune build
```

## Usage
From the root directory of this repository, run:
```bash
./bin/main.exe <path/to/.lex file>
```

e.g.
```bash
./bin/main.exe examples/hello.lex
```
